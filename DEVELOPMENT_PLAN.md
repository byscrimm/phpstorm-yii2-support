# План развития PhpStorm Yii2 Support

Цель: удобная и предсказуемая поддержка Yii2 в PhpStorm 2026.2. Сохраняем совместимость с 262.* и существующий ID плагина.

## Подготовка форка — 2026-09-08

- [x] Git-история, `origin` нового форка и `upstream` исходного проекта.
- [x] README на английском и русском, возможности, происхождение и участие AI.
- [x] AGENTS.md, память проекта, правила разработки/выпуска, шаблоны issue/PR.
- [x] Исправление унаследованной конфигурации Renovate, ограничение CI по времени.
- [ ] Подтверждённый запуск GitHub Actions и официального Plugin Verifier.

## 1. Проверки и воспроизводимая сборка — локальный контур готов

- [x] Сборка через установленный SDK, регрессии вспомогательной логики, проверка JVM-ссылок.
- [x] Тесты PHP PSI: конфиги, связи, именованные аргументы, вложенные массивы и незавершённый код.
- [ ] Регрессии автодополнения, навигации и переименования на Yii2 Basic/Advanced.
- [x] Обновить Docker, Makefile, CI, инструкции; сохранять отчёт рядом с ZIP.
- [ ] Выполнить Docker/Gradle-сборку в среде с разрешённой загрузкой зависимостей.
- [ ] Полный JetBrains Plugin Verifier и запуск тестового профиля IDE.

Ограничения среды: загрузка Gradle ранее не разрешена; отдельный профиль IDE остановился с `No valid license found`. Эти проверки не считаются пройденными. Независимые проверки продолжаем локально.

## 2. ActiveRecord и связи — первый инкремент реализован

- [x] Общий механизм определения модели по `Model::find()`, переменным запроса и `hasOne/hasMany`.
- [x] Дополнение связей в `with`, `joinWith`, `innerJoinWith`, `getRelation`, `via`.
- [x] Вложенные связи `orders.items.product`, ключи массивов с callback и алиасы JOIN.
- [x] Переход к getter каждой части пути; переименование конкретного сегмента.
- [x] Фильтрация: обычные getter и строки SQL не должны становиться связями.
- [x] Тесты положительных и отрицательных сценариев, сохранение корректных типов `asArray`.

## 3. GridView и DetailView

- [ ] Модель из `ActiveDataProvider.query`, включая локальные переменные.
- [ ] Атрибуты и вложенные связи; понимание формата `attribute:format:label`.
- [ ] Тип первого параметра callback `value`, включая стрелочные функции; остальные параметры не получают тип модели.
- [ ] Отказ от жёстких чисел уровней PSI при поиске контекста виджета.

## 4. Views

- [ ] Именованные аргументы render-методов, `compact`, параметры в переменной.
- [ ] Передача доступных типов во view, диагностика только достоверных ошибок.
- [ ] Исправления сохраняют существующие аргументы и комментарии.
- [ ] Индекс views не зависит от настроек конкретного проекта; фильтрация в момент запроса.

## 5. Конфигурация и DI

- [ ] Статически определимые `require` и `ArrayHelper::merge`, порядок переопределения конфигов.
- [ ] Контейнер: интерфейс → реализация, определения компонентов и service locator.
- [ ] Корректное разделение приложений, общий конфиг, локальные переопределения.
- [ ] Ограничение глубины и циклов; произвольный PHP-код не исполняется.

## 6. Маршруты и переводы

- [ ] `controllerMap`, нестандартные пути контроллеров, REST, параметры action.
- [ ] Конфигурация источников переводов: `basePath`, `fileMap`, язык приложения.
- [ ] Переход к переводу, создание ключа и проверка ICU-параметров.

## 7. Производительность и выпуск

- [ ] Отмена длительных операций; отсутствие чтения индексов из индексаторов/type-provider getType.
- [ ] Кэши инвалидируются по релевантным изменениям, не удерживают закрытый проект.
- [ ] Профиль большого проекта, повторное открытие проекта и изменение конфигов.
- [ ] Новый ZIP, changelog и отчёт с чётким разделением выполненных/невыполненных проверок.

Первый инкремент: инфраструктура проверок и поддержка связей. Следующие этапы опираются на общий механизм определения модели, чтобы GridView и views не имели разных несовместимых эвристик.

## Результат первого инкремента

- Версия: `1.1.0-rc.1`, SDK PhpStorm `2026.2.2 / 262.10315.130`.
- 148 проверок вспомогательной логики и 52 проверки на реальном PHP PSI, включая изменение строки обработчиком переименования.
- Таблица PHP-классов в Core-тестах задаётся тестом. Полный индекс, UI автодополнения и весь процесс Find Usages/Rename в IDE пока не проверены.
- Следующий инкремент: GridView/DetailView с определением модели из `dataProvider`, расширение разрешения пользовательских Query-методов и типизированных параметров.
- Исходная версия сохранена в `build/baseline-1.0.0-source.zip`.
