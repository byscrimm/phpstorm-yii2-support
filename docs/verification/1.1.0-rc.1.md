# Проверка Yii2 Support Extended 1.1.0-rc.1

Дата: 2026-09-08. Исторический отчёт локального RC-артефакта. Не является результатом GitHub Actions или гарантией для последующих изменений.

Архив: `yii2-support-extended-1.1.0-rc.1.zip` (295982 байт).

SDK: PhpStorm 2026.2.2, build 262.10315.130, Java 25.

SHA-256: `209c17977f05757517f33d9e13a44f614c37ac574f042f6c460b94150efed8a4`.

## Выполнено

- Все Java-исходники скомпилированы против установленного SDK.
- 148 проверок вспомогательной логики: алиасы, SQL, маршруты, вывод миграций и разбор путей связей.
- 52 проверки реального PHP PSI: именованные аргументы, модели и связи, query-переменные, вложенные пути, JOIN-алиасы, отрицательные сценарии, обработчик переименования, незавершённый PHP и режим asArray.
- PASS: 182 plugin classes; JVM class/member references and descriptor checked against 1272 SDK jars
- Проверены целостность ZIP/JAR, версия дескриптора, наличие новой функциональности и отсутствие тестовых классов в плагине.
- Исходная версия 1.0.0 сохранена отдельно; данные профиля рабочего PhpStorm не менялись.

## Не выполнено

- Полный запуск плагина в активированном профиле IDE и проверки интерфейса автодополнения.
- Полный индекс PhpStorm, весь процесс Find Usages/Rename и навигация между физическими файлами проекта.
- Docker/Gradle-сборка и официальный JetBrains Plugin Verifier: загрузка зависимостей ранее не была разрешена.

Таблица классов в Core-тестах задаётся тестом; это не имитация PHP-парсера — парсер, PSI, ссылки и обработчик изменения строки используются из настоящего SDK. Проверка JVM-ссылок не заменяет Plugin Verifier.

Следующие этапы описаны в [DEVELOPMENT_PLAN.md](../../DEVELOPMENT_PLAN.md). GridView/dataProvider, расширенные views и DI не входят в завершённый первый инкремент.
